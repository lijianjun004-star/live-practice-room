# 小小练播房

手机优先的免费弹幕练习工具。无需访问者账号，话术保存在访问者自己的浏览器里。

粘贴弹幕（一行一条），设置 0.5–15 秒间隔，选择顺序或随机播放，开始练播。
支持指定昵称（`小王 | 这款多少钱？`）、循环、暂停、TXT 导入导出、离线页面保存。
语音是可选功能：首次准备中文模型资源后，使用浏览器内 Vosk 识别并按关键词触发预设话术。

本目录是可直接部署到 GitHub Pages 的静态网站，不需要构建。发布源选择默认分支的根目录。
首次联网打开后，可通过页面右上角准备离线资源；手机添加到桌面后请从桌面联网打开一次，再确认离线状态。
